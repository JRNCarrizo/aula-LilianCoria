Una sola vez: claves de Google

Para que el aula pueda guardar en Drive sin que entre nadie a drive.google.com, hay que crear un proyecto en Google Cloud y pegar acá el Client ID y la API Key. Se editan en js/admin-config.js.

  1. Entrá a Google Cloud Console y creá un proyecto.
  2. Activá la API de Google Drive.
  3. Credenciales: Client ID para “Aplicación web”. En orígenes autorizados poné la URL del aula (Netlify) y http://localhost:5173.
  4. Creá también una API Key restringida a este sitio.
  5. Pegá los dos valores en js/admin-config.js y volvé a subir el sitio.
